GitHub CLI & Stacked PR Cheatsheet

1. Authentication & Setup

# Check GitHub login status
gh auth status

# Login if needed
gh auth login

2. Branching & Atomic Work

# Always branch from latest main
git checkout main
git pull origin main
git checkout -b feat/your-feature-name

# Make atomic commit
git add .
git commit -m "feat(scope): concise description"

3. Push Branch & Create PR with gh

# Push branch to remote
git push -u origin feat/your-feature-name

# Create pull request via gh CLI
gh pr create --base main --head feat/your-feature-name --title "feat(scope): concise description" --body "Summary of changes"

4. Merging with Merge Commit (--no-ff)

# Merge via PR with merge commit (no fast-forward)
gh pr merge <pr-number-or-branch> --merge --delete-branch

# Update local main
git checkout main
git pull origin main
